# Advent of Code &middot; Solutions 🎄
Welcome to my *Advent of Code* solutions repository!  
Here, I’ll document my journey solving the yearly *Advent of Code* challenges.


## What is Advent of Code?
[Advent of Code](https://adventofcode.com/) is an annual set of programming puzzles that run from December 1st to 25th.  
Each day, two puzzles are released, designed to challenge your coding, problem-solving, and algorithmic skills.  
It’s a fun way to celebrate the holidays while sharpening your coding skills.


## Structure
This repository organizes solutions into yearly challenges.  
Within each folder, solutions are named according to the day the problem was posted and include all relevant files where applicable.


## Solutions
I'm using python to solve each challenge as a way of sharpening my skills.  
If Python isn't already available on your system, follow the instructions found at the official [Python site](https://www.python.org/) to install it on your computer.
